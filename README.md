# KnulliVietHoa — Gói Việt hoá cho Knulli OS

Vá font hết ô vuông + bản dịch tiếng Việt đầy đủ cho menu của Knulli OS
(EmulationStation) trên handheld TrimUI Brick.

## Tải về

Vào mục **Releases** của repo này, tải file `KnulliVietHoa-vX.Y.Z.zip`
mới nhất, giải nén vào thư mục gốc của thẻ nhớ (gộp thư mục), mở máy,
chọn **Ports → KnulliVietHoa**, bấm **A** ở dòng Việt hoá, rồi khởi động
lại máy. Chi tiết có trong file `HUONG-DAN-CAI-DAT.txt` kèm trong ZIP.

Từ v0.3.1, app có mục **Kiểm tra cập nhật** để tự tải bản mới qua OTA
(manifest trong thư mục `ota/` của repo này, đã ký Ed25519).

Mã nguồn: repo private của tác giả.
